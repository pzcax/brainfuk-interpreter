Super simple brainfuck interpreter i made to learn how to use i/o and pointers

**>	Move the data pointer to the right**

**<	Move the data pointer to the left**

**+	Increment the byte value at the data pointer**

**-	Decrement the byte value at the data pointer**

**.	Output the byte value as an ASCII character**

**,	Accept a character of input and store it in the current byte**

**[	Jump past the matching ] if the current byte is 0**

**]	Jump back to the matching [ if the current byte is not 0 (starts a loop)**
